A digital payments platform with P2P transfers, multi-currency wallets, virtual cards, and spending analytics, built as a monorepo with an **ASP.NET Core** API, a **React** web app, and an **Expo** mobile app. The User role is wired end-to-end across web, mobile, and API.

**Built with:** ASP.NET Core 10, EF Core, React, TanStack Router, shadcn/ui, Tailwind v4, Expo SDK 57, React Native, Turborepo, Biome
