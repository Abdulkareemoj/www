One reader for everything you read, look at, and listen to comics (CBZ), ebooks (EPUB, MOBI, PDF), and audiobooks (MP3, M4A, FLAC, OGG, WAV) in a single local-first library. Browse and read manga online via MangaDex. Your files stay on your machine; there is no account and no server. Available as web, desktop (Tauri v2), and mobile (Expo) apps.

**Built with:** TanStack Start, React 19, Tauri v2, Expo, React Native, Drizzle ORM, Tailwind CSS v4, Base UI, Uniwind
