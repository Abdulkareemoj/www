A cross-platform marketplace app (iOS, Android, web) where multiple vendors run their own storefronts and customers shop across all of them in a single cart. Includes role-based access for customers, vendors, and admins, with order splitting and fulfillment tracking.

**Built with:** React Native (Expo), Hono, PostgreSQL, Better Auth, Cloudflare R2
